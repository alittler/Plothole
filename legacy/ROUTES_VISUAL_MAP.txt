                       BLOCKERS & SOLUTIONS

BLOCKER 1: MULTER FILE UPLOADS
─────────────────────────────
Problem:  Multer is Express middleware, not compatible with Next.js
Solution: Use 'formidable' or 'busboy' library for multipart parsing
Impact:   Routes 1, 2 require refactoring
Work:     ~4 hours for basic setup

BLOCKER 2: LOCAL DISK I/O
─────────────────────────
Problem:  Vercel serverless has no persistent disk storage
Solution: Move all file storage to S3
Impact:   Routes 1-5 require S3 migration
Work:     ~6 hours for implementation

BLOCKER 3: GIT OPERATIONS
─────────────────────────
Problem:  simple-git needs local .git directory (not available on Vercel)
Solution: Use separate sidecar service OR GitHub API integration
Impact:   Routes 7-11 require architecture change
Work:     ~8-12 hours depending on approach

BLOCKER 4: CHILD PROCESS EXECUTION
───────────────────────────────────
Problem:  execSync() doesn't work reliably on Vercel
Solution: Use environment variables or build-time version info
Impact:   Route 17 needs refactoring
Work:     ~1 hour

BLOCKER 5: JWT MIDDLEWARE
─────────────────────────
Problem:  express-oauth2-jwt-bearer is Express-only
Solution: Manual JWT verification with 'jose' library
Impact:   All 15 protected routes need code changes
Work:     ~2 hours to implement once, ~30 mins per route
